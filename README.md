# สมุดดูแลรถ (BikeLog)

PWA สมุดดูแลรถมอเตอร์ไซค์ ตั้งค่ามาสำหรับ GPX Drone 150 4V (2023)
เปิดใช้: https://yuttachaicp-ops.github.io/bikelog/

- บันทึกการเติมน้ำมัน พร้อมคำนวณ กม./ลิตร และค่าน้ำมันต่อกิโล
- รอบเปลี่ยนอะไหล่ เตือนเมื่อถึงระยะทางหรือเวลา
- ประวัติซ่อมและค่าใช้จ่าย พร้อมกราฟ 6 เดือน
- วันหมดอายุ พ.ร.บ. / ภาษี / ประกัน / ใบขับขี่ และปุ่มเพิ่มลง Google Calendar
- ใช้แบบออฟไลน์ได้ และซิงก์ข้อมูลขึ้น Supabase (ตาราง `bikelog_state` แถวเดียวต่อผู้ใช้ ป้องกันด้วย RLS)

## การ deploy
ทุกครั้งที่ push เข้า `main` ไฟล์ `.github/workflows/pages.yml` จะแปลงไอคอน SVG เป็น PNG แล้ว deploy ขึ้น GitHub Pages ให้อัตโนมัติ

## อัปเดตแอพ
ถ้าแก้ไฟล์ ให้เปลี่ยน `VERSION` ใน `sw.js` ทุกครั้ง มือถือจะได้โหลดเวอร์ชันใหม่ ส่วนข้อมูลเดิมไม่หาย
